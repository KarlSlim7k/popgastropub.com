# Animaciones UI — POP Perote

## Efectos usados en promociones

| Nombre común | Qué hace | Dónde verlo |
|-------------|----------|-------------|
| **Fade-in Up** | Aparece suave subiendo desde abajo | Títulos y textos del hero |
| **Stagger (cascada)** | Los elementos entran uno tras otro | Días del calendario, tarjetas de promos |
| **Scroll Reveal** | Se activan al llegar al área visible | Agenda Semanal, Más Promociones, Próximamente |
| **Hover Lift** | Tarjeta se eleva al pasar el mouse | Tarjetas de promoción |

## Librería: Framer Motion
