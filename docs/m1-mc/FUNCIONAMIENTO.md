# Funcionamiento — Marketing y Campañas

## 1. ¿Qué es Marketing y Campañas?

**Marketing y Campañas** será un módulo del panel administrativo de POP PEROTE para crear promociones, eventos especiales y campañas con páginas individuales listas para compartir.

Cada campaña tendrá su propio enlace. El equipo podrá publicarlo en Facebook, Instagram, TikTok, WhatsApp o anuncios para llevar al cliente directamente a la promoción.

## 2. Problema que resuelve

Actualmente las promociones se consultan dentro de la página general de promociones. Un cliente puede perderse buscando la oferta que vio en redes sociales.

Con esta mejora, cada promoción tendrá un enlace directo. El cliente abrirá una página dedicada con la información y la acción principal: pedir, mandar WhatsApp, reservar o dejar sus datos.

## 3. Ejemplos de uso

El módulo podrá utilizarse para campañas como:

- Sushiércoles.
- Noche de alitas.
- Promoción de cumpleaños.
- Evento especial.
- Día del Padre.
- Promoción exclusiva por WhatsApp.

## 4. Flujo para el administrador

1. Iniciar sesión en el panel administrativo.
2. Entrar a **Marketing y Campañas**.
3. Crear una nueva campaña.
4. Subir la imagen principal.
5. Agregar título, descripción, beneficio y fechas.
6. Configurar el botón principal, por ejemplo **Pedir ahora** o **Enviar WhatsApp**.
7. Activar un formulario si desea captar datos.
8. Previsualizar cómo verá la campaña el cliente.
9. Publicar la campaña.
10. Copiar el enlace.
11. Compartirlo en Facebook, Instagram, TikTok o WhatsApp.

## 5. Flujo para el cliente

1. Ve una publicación o anuncio en redes sociales.
2. Da clic en el enlace.
3. Entra directamente a la landing de la promoción.
4. Lee el beneficio y las condiciones.
5. Presiona el botón de acción.
6. Puede pedir, mandar WhatsApp, reservar o dejar sus datos.

## 6. Beneficios para POP PEROTE

- Facilita compartir promociones.
- Mejora la experiencia del cliente.
- Aumenta la conversión desde redes sociales.
- Mantiene las promociones más ordenadas.
- Da mayor control desde el panel administrativo.
- Permite captar datos de clientes cuando sea útil.
- Ayuda a medir cuáles campañas funcionan mejor.
- Reduce la dependencia de cambios manuales en la página principal.

## 7. ¿Qué podrá configurar el administrador?

| Elemento | Uso |
|---|---|
| Nombre de la campaña | Identificar la promoción o evento. |
| Imagen | Mostrar una pieza visual atractiva. |
| Descripción | Explicar beneficio y condiciones. |
| Fechas | Definir vigencia o recurrencia. |
| Estado | Activar, pausar o finalizar. |
| Botones | Dirigir al cliente a la acción principal. |
| Enlaces | Conectar con pedidos, WhatsApp, ubicación o reserva. |
| Formulario | Captar datos cuando la campaña lo requiera. |
| Vista previa | Revisar antes de publicar. |
| Publicación | Hacer visible la página individual. |

## 8. Ejemplo de landing

Una landing de **Sushiércoles** podría mostrar:

- Imagen principal de la promoción.
- Nombre de la promoción.
- Beneficio destacado.
- Condiciones y vigencia.
- Botón **Pedir ahora**.
- Botón **Enviar WhatsApp**.
- Formulario opcional.
- Ubicación o datos de contacto.

El enlace podría compartirse como:

`https://popgastropub.com/promo/sushiercoles`

## 9. Métricas disponibles

El administrador podrá consultar:

- Cuántas personas visitaron la promoción.
- Cuántas dieron clic en los botones.
- Cuántas dejaron sus datos.
- Qué campañas funcionan mejor.

Estas métricas ayudarán a decidir qué promociones repetir, mejorar o pausar.

## 10. Etapas sugeridas

| Etapa | Resultado |
|---|---|
| Primero | Crear enlaces individuales para promociones. |
| Después | Personalizar textos, imágenes y botones. |
| Luego | Agregar formularios opcionales. |
| Finalmente | Agregar métricas y reportes. |

## 11. Resultado esperado

POP PEROTE tendrá un módulo más profesional para lanzar campañas rápidamente, compartirlas en redes sociales y medir resultados sin depender de cambios manuales en la página principal.
